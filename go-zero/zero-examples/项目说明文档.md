# go-zero 示例项目说明文档

本文档详细说明了 go-zero 示例项目中各个实例的功能和用途。

## 目录结构概览

```
.
├── bloom           # 布隆过滤器示例
├── bookstore       # 书店微服务示例（多RPC调用）
├── breaker         # 熔断器示例
├── chat            # WebSocket聊天室示例
├── config          # 配置管理示例
├── discovery       # 服务发现示例
├── etcd            # etcd集成示例
├── filex           # 文件操作示例
├── fx              # 函数式编程工具示例
├── gateway         # 网关示例
├── graceful        # 优雅停机示例
├── http            # HTTP功能示例集合
├── limit           # 限流器示例
├── load            # 负载模拟示例
├── logging         # 日志处理示例
├── logx            # 日志框架示例
├── mapreduce       # MapReduce并发处理示例
├── mon             # 监控指标示例
├── monolithic      # 单体应用示例
├── periodicalexecutor # 定期执行器示例
├── pool            # 连接池示例

├── shorturl        # 短链接服务示例

├── siphash         # SipHash算法示例
├── stat            # 统计信息示例

├── syncx           # 同步工具示例
├── timingwheel     # 时间轮示例
└── tracing         # 链路追踪示例
```

## 各示例详细说明

### 1. 核心微服务示例

#### shorturl - 短链接服务示例
- 展示了 go-zero 中 API Gateway + RPC 微服务的基本用法
- 包含两个核心功能：生成短链接、解析短链接
- 演示了 API 和 RPC 之间的调用关系
- 展示了服务配置、业务逻辑分层等最佳实践

#### bookstore - 书店服务示例
- 展示了多个 RPC 服务协同工作的场景
- 包含 add（添加书籍）和 check（检查库存）两个 RPC 服务
- 演示了复杂的微服务架构设计
- 展示了服务间通信和服务治理

#### monolithic - 单体应用示例
- 展示了如何在单体应用中使用 go-zero
- 包含文件上传等常见功能
- 演示了非微服务架构下的使用方式

### 2. 中间件与基础设施示例

#### bloom - 布隆过滤器示例
- 展示了布隆过滤器的使用方法
- 演示了基于 Redis 的布隆过滤器实现
- 用于大数据去重和存在性检测场景

#### breaker - 熔断器示例
- 展示了如何使用 go-zero 内置的熔断器功能
- 包含可视化图表展示熔断效果
- 演示了在高负载情况下保护系统稳定性
- 通过模拟服务状态变化展示熔断器的工作原理

#### chat - WebSocket 聊天室示例
- 实现了一个简单的 WebSocket 聊天室
- 展示了实时双向通信的实现方式
- 演示了消息广播和客户端管理机制
- 包含客户端和服务端的完整实现

#### limit - 限流器示例
- 展示了令牌桶限流器和周期限流器的使用
- 演示了如何控制服务访问频率
- 展示了限流策略的配置和使用
- 包含基于 Redis 的分布式限流实现

### 3. 网络与通信示例

#### graceful - 优雅停机示例
- 展示了 DNS 和 etcd 模式下的优雅停机实现
- 演示了服务平滑升级和停止

#### http - HTTP 功能集合
- 包含多个子示例：
  - breaker: HTTP 熔断器使用
  - cors: 跨域资源共享配置
  - demo: HTTP 服务基础示例
  - download: 文件下载功能
  - group: HTTP 请求分组
  - httpc: HTTP 客户端示例
  - jwt: JWT 认证示例
  - middleware: 中间件使用
  - post: POST 请求处理
  - shedding: 请求削峰填谷
  - signature: 请求签名验证
  - sse: Server-Sent Events 实现
  - static: 静态文件服务
  - timeout: 超时控制
  - upload: 文件上传功能
  - wildcard: 通配符路由
  - withtimeout: 带超时控制的 HTTP 服务

#### rpc - RPC 调用示例
- 包含完整的 RPC 调用示例
- 展示了直连、负载均衡、流式传输、一元调用等多种 RPC 模式
- 包含代理服务器示例

#### gateway - 网关示例
- 展示了如何构建 API 网关
- 演示了服务聚合和路由转发
- 包含 TLS 加密通信示例

### 4. 配置与服务治理示例

#### config - 配置管理示例
- 展示了如何从 TOML 和 YAML 文件加载配置
- 演示了不同配置格式的使用方法
- 包含配置项校验和默认值设置

#### discovery - 服务发现示例
- 包含多种服务发现机制：
  - consul: Consul 服务发现
  - k8s: Kubernetes 服务发现
  - nacos: Nacos 服务发现
  - polaris: Polaris 服务发现

#### etcd - etcd 集成示例
- 展示了如何使用 etcd 进行服务注册与发现
- 包含发布者和订阅者模式的实现

#### graceful - 优雅停机示例
- 展示了 DNS 和 etcd 模式下的优雅停机实现
- 演示了服务平滑升级和停止

### 5. 日志与监控示例

#### load - 负载模拟示例
- 展示了如何模拟系统负载
- 包含 CPU 负载和网络负载的模拟
- 用于测试系统的性能表现
- 包含可视化图表展示负载效果

#### logging - 日志处理示例
- 展示了基本的日志记录功能
- 包含日志重定向示例

#### logx - 日志框架示例
- 展示了 go-zero 内置日志框架的高级用法
- 包含多种日志输出方式：
  - fileconsole: 文件和控制台输出
  - filterfields: 字段过滤
  - logrus: 与 logrus 集成
  - tokafka: 日志发送到 Kafka
  - zaplog: 与 zap 日志库集成
  - zerolog: 与 zerolog 集成

#### mon - 监控指标示例
- 展示了如何收集和上报监控指标
- 演示了系统性能监控

#### stat - 统计信息示例
- 展示了统计信息收集和处理
- 演示了服务状态监控

#### tracing - 链路追踪示例
- 展示了分布式链路追踪的实现
- 演示了请求在多个服务间的流转跟踪
- 包含边缘服务、门户服务、远程服务和用户服务的完整调用链

### 6. 数据处理与算法示例

#### mapreduce - MapReduce 并发处理示例
- 展示了 MapReduce 并发模型的实现
- 包含多种并发处理场景：
  - countfunc: 函数计数
  - deadlock: 死锁检测
  - finishvoid: 无返回值任务处理
  - flatmap: 扁平映射处理
  - goroutineleak: Goroutine 泄漏检测
  - irregular: 不规则数据处理
  - mr: MapReduce 基础示例

#### mon - MongoDB 操作示例
- 展示了如何使用 go-zero 操作 MongoDB
- 演示了增删改查等基本操作
- 包含 ObjectID 的使用示例

#### monolithic - 单体应用示例
- 展示了如何在单体应用中使用 go-zero
- 包含文件上传等常见功能
- 演示了非微服务架构下的使用方式

#### siphash - SipHash 算法示例
- 展示了 SipHash 一致性哈希算法的使用
- 演示了数据分片和负载均衡
- 包含哈希分片测试用例

#### stat - 统计信息示例
- 展示了统计信息收集和处理
- 演示了服务状态监控
- 包含 CPU 使用率监控

#### stringx - 字符串处理示例
- 展示了字符串过滤和替换功能
- 演示了高效的字符串处理技巧
- 包含敏感词过滤和字符串替换功能

### 7. 系统工具示例

#### syncx - 同步工具示例
- 展示了共享调用（SharedCalls）等同步工具的使用
- 演示了并发控制和资源共享
- 包含防缓存击穿的 SingleFlight 模式

#### timingwheel - 时间轮示例
- 展示了时间轮算法的实现
- 演示了高效定时器的使用
- 包含传统定时器与时间轮的性能对比

#### servicegroup - 服务组示例
- 展示了如何管理一组相关服务
- 演示了服务生命周期管理
- 包含多个服务的统一启停控制

#### signal - 信号处理示例
- 展示了系统信号的捕获和处理
- 演示了程序优雅退出
- 包含 goroutine 转储功能
